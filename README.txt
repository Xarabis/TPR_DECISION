DECISION / 01 — Pilot 7: кинематографичное интро, интерактивная игра и индивидуальная ветка лифта.

ОТКРЫТЬ ПРЕЗЕНТАЦИЮ (в браузере ведущего):
  https://tprdecision-production.up.railway.app/film?k=ВАШ_HOST_KEY
  Пробел — запустить кинематографичное интро. После ~22 секунд оно останавливается.
  Пробел ещё раз — перейти к лобби /host?k=ВАШ_HOST_KEY.
  S — пропустить интро. F — полноэкранный режим.

В лобби посетители сканируют QR-код (ведёт на /play) и вводят имена.
  Пробел или стрелка вправо — перейти к следующему этапу: голосование →
  закрытие → результаты → новый этаж. Действие не происходит без клика ведущего.
  В финале пробел показывает анимированное дерево решений / backward induction.
  Математика изменена с учетом личного возврата: EV лифта = 0,7×240 + 0,3×150 = 213;
  EV лестницы = 180; на 1-м этаже EV оптимальной стратегии = 0,8×213 = 170,4.
  Повторный пробел возвращает рейтинг. R — новая игра, F — полный экран.

ЛИФТ НА ЭТАЖЕ 2:
  70% — поднимает игрока на этаж 3 с прежним золотом.
  30% — возвращает ТОЛЬКО ЕГО на этаж 1, сохраняя 150 золота.
  На его телефоне проигрывается анимация спуска и появляется кнопка «ОТКРЫТЬ ДВЕРЬ».
  Дальше он принимает решения самостоятельно на этажах 1, 2 и 3:
    забрать золотые ИЛИ рискнуть (80%, 60%, 20% соответственно).
  После успеха он вручную открывает следующий этаж; при провале теряет золото.
  Остальные участники продолжают общую игру без перезапуска.
  Если групповая игра окончена раньше личных веток, ведущий видит экран ожидания.
  Финал становится доступен, когда все персональные маршруты завершены.
  Если игра затягивается: на экране ожидания нажмите E, подтвердите досрочное
  завершение личных маршрутов с сохранением золота в руках.

DEPLOY / RAILWAY:
  1) Распакуйте файлы проекта (НЕ сам ZIP как ZIP) в корень репозитория.
  2) git add .
     git commit -m "Add cinematic intro and solo lift adventure"
     git push origin main
  3) Railway обновит сервис (если GitHub Autodeploy включён).
  4) Переменная HOST_KEY должна быть задана в Railway Variables (длинный секрет).
  5) Одна реплика; npm start; healthcheck /healthz; PORT задаёт Railway.
  6) Не деплойте посреди выступления: данные хранятся в памяти Node.js.

ПРОВЕРКИ:
  /healthz -> ok
  /play -> мобильная регистрация
  /host?k=ВАШ_HOST_KEY -> управление ведущего
  /film?k=ВАШ_HOST_KEY -> кинематографичное интро

ВНИМАНИЕ: Анимация вступления взята из версии 2; это отдельный 3D-пилот
перед игрой. Остальные motion-переходы реализованы как короткие анимации
этапов в интерфейсе ведущего и личного приключения на телефоне.
